# Changelog

All notable changes to Projects Emergence will be documented in this file.

## [0.1.0-beta] - 2026-08-23

### Added

- Public, environment-neutral `projects-emergence` Agent Skill.
- Proportionate research routing and evidence-based stopping conditions.
- Replicate, adapt, improve, and redesign project paths.
- Research confirmation gate before substantial implementation.
- Reflection and research re-entry loop for five project types.
- Optional research, reflection, and project metadata templates.
- Optional portfolio, multi-project, and worktree coordination guidance.
- Skills-only Codex plugin manifest and OpenAI UI metadata.
- English and Simplified Chinese documentation.
- Eight behavior-focused beta evaluation cases.

### Known limitations

- External users and non-Codex hosts have not yet been evaluated systematically.
- Templates are intentionally generic and require adaptation to established repositories.
- The beta includes no knowledge-base, deployment, or external-service automation.
